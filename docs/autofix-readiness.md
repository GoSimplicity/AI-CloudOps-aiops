# 修复动作与就绪结果

API 接受 Kubernetes 补丁不代表工作负载已经恢复。AutoFix 执行后要求 post_check.ready 严格为 true 才返回 completed；False、缺失、无效类型和检查异常均为 failed，保留已提交动作与实际检查结果供核对

首个动作失败后停止后续写入，not_attempted_actions 列出未尝试项。异常正文可能包含资源敏感配置，因此动作/就绪错误只记录异常类型和固定提示，不回显底层正文。失败状态不等于回滚，也不证明没有副作用；审批工作流会消费原计划并要求核对实际目标，不能盲目重试

验证：先红复现7项（未就绪仍completed、失败后继续写、异常正文回显），修复后结合既有修复/审批/工作流共76项通过。真实Kubernetes验收与模型调用单独记录，不将替身状态当作集群已恢复
