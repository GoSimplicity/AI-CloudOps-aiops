# 预测滚动回测与误差校准

`POST /api/v1/predict/backtest` 接收同一指标、同一模型和同一预测跨度的已记录样本。每项包含 `issued_at`（预测产生时间）、`target_at`（预测目标时间）、`observed_at`（实际值可用时间）、`forecast` 和 `actual`。时间必须包含时区，预测须早于目标时间，观测不能早于目标时间，目标时间不能重复；不同跨度分别评估。每次最多 5000 条，调用方需持有该 API 的 POST 权限。接口不存储记录，不调用模型或外部服务。

返回 MAE、RMSE、偏差、WAPE 和经验残差区间。WAPE 在实际值绝对和为零时为 `null`。滚动覆盖率仅使用发出该次预测时已经可用的历史残差，窗口和最少历史样本均可配置，样本不足时覆盖率和区间为 `null`。返回的最新残差区间仅供同一指标、模型与跨度的后续预测参考，不保证真实覆盖率；不要将它当成置信概率。

这些结果基于调用方提供的记录，不能证明模型训练数据与回测数据隔离，也不会自动改写模型元数据、模型准确率或生产预测。请求格式错误不会回显记录；请求中止后计算仍占用受限并发槽直到线程结束。未使用真实历史指标或模型，本阶段验证采用合成数据和本地 ASGI 请求。
