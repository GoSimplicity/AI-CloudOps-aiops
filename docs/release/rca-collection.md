# RCA 数据采集状态

RCA 普通分析和快速诊断报告 `completed`、`degraded` 或 `failed`。响应 `collection.sources` 分别标记指标、事件和日志的成功、空结果、部分失败或失败；工作单元的成功覆盖率在已知时提供，事件/日志触及截断上限时为未知。公开结果只包含固定错误类别，不包含凭据或上游异常正文。

全部采集失败返回 failed，部分失败返回 degraded；仅完整结果可进入分析缓存，旧的不含采集状态的缓存不会冒充完整结果。Kubernetes 严格错误传播只用于RCA，其他调用默认保持原有合同。依赖启动不可用时保留失败状态，并由后续请求触发有界冷却重连；同一数据源的并发请求共享连接尝试。底层同步连接线程无法强制终止，若线程永久阻塞，请求仍会超时，但需线程返回或进程重启后才能再次连接。

本阶段使用真实ASGI路由与离线依赖替身验证正常空结果、局部/全部失败、截断、旧缓存和权限边界；未访问实际集群或监控服务。
