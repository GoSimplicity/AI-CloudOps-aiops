# 智能助手持久会话

生产助手会话按当前可信用户隔离并保存到唯一权威 Redis，保存最近 25 轮完整问答和有界请求去重状态。HTTP 与 WebSocket 接收可选 `turn_id` UUID；同用户、会话、ID 和请求内容一致时，已完成请求返回已保存结果，不再次调用模型或工具；内容冲突、处理中或状态不确定时拒绝重放。未提供 ID 的旧客户端只适用于当前只读助手能力，丢失响应后的手动重发不承诺去重。

每个会话跨进程独占处理，租约失效后保留 `unknown`，按用户查询待核对的问题和 ID，不自动重新执行。会话详情提供状态、修订和历史；空闲会话一小时过期，未知状态不自动清理并占用配额，每用户最多 50、全局最多 1000。达到容量上限会拒绝新会话，须对未知状态建立人工核对及运维治理流程。历史作为不可信用户数据传给 RAG 和 MCP，不享有系统指令权限；工具仍受原有只读与授权限制。

运行要求 Redis 7.2+、持久 AOF、`noeviction` 和可用的 `WAITAOF`；服务账号必须能执行 EVAL、读取淘汰策略及持久化确认，但不得修改 Redis 配置。运行期间必须禁止管理员修改淘汰策略，客户端检查不能消除外部配置修改与淘汰之间的竞态。Redis Cluster、异步主从故障切换、旧备份恢复或持久卷丢失未验证为零丢失，需停写并人工核对。升级前停止旧进程，旧内存会话不可迁移；未连接生产或真实模型。
