# 预测来源与报告合同

每次预测携带实际 `method`、`model_version`、模型 `fallback_reason`；AI增强的状态和 `ai_fallback_reason` 独立，不将AI失败误标成模型降级。没有有效回测依据的精度、预测点置信度、区间和建议置信度返回 null，调用方应显示未知，不转换为0%。

单维及多维均先完成基础预测、异常/扩缩容/成本分析，再生成解释和报告；单项分析失败显式记录 `analysis_failures`，不能伪造空结果或零成本。分析ID随机生成，报告快照按可信主体隔离、最多100条、有效2小时；当前进程重启或跨实例后须重新预测。

验证：94项预测/真实ASGI离线回归，覆盖模型与规则降级、AI失败、无依据精度、单维/多维报告输入、并发ID、主体隔离与到期；未连接真实模型或监控。
